# Security Test Cases and Results (Part 2)

16 test cases, 2 per the 8 categories in the brief. Executed 2026-11-13 against a local copy only (`http://localhost:8090`, seeded test database, test accounts). The live site was never tested.

- **Roles:** guest · customer A (`customer.a@lumeegy.test`) · customer B (`customer.b@lumeegy.test`) · admin (`admin@lumeegy.test`).
- **Method:** every test has a **positive control** (the same action works for the right user), so a blocked result proves the security control acted, not that the page is broken.
- **Tools:** Burp Suite Community (Repeater, Intruder, Proxy intercept), sqlmap, curl, browser DevTools. See [tools.md](tools.md).
- **Result: 16 / 16 pass, 0 findings.** Evidence under `evidence/tests/`, `evidence/burp/`, `evidence/sqlmap/`.

Each row's control is given with the finding. The "Control/Defence" column names the code that blocked the attack: `h()` (output escaping), prepared statements, `csrf_verify()` / `admin_enforce_csrf()`, `auth.php`, `can_view_order()`, and Part 1 controls C1–C4 / H2–H3.

## Findings

**None.** All 16 tests passed; every attack was blocked by an existing control or a Part 1 control. No vulnerability was confirmed in Part 2, so there is no fix/retest cycle to record here. The static true positives that Part 1 fixed are tracked in [semgrep-triage.md](semgrep-triage.md); the baseline dynamic alerts and their disposition are in [findings.md](findings.md).

## Notes

- **Burp vs curl.** Tests marked "curl" were scripted for repeatability, but each exercises the same request a Burp Repeater/Intruder user would send; AUTH-01 and the upload tests were run through Burp directly (screenshots in `evidence/burp/`). Using curl for the rest kept the run fast and the evidence exact.
- **GD during UPL-02.** The local Apache had PHP-GD disabled, so the first manual `real-ring.jpg` upload threw `imagecreatefromjpeg()` *after* passing the security check. GD was enabled and Apache restarted; the upload then stored normally. The security logic was never changed. See [local-setup.md](local-setup.md).
